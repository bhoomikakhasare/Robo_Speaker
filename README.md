**ROBO SPEAKER**
# 🎙️ Robo Speaker

**Robo Speaker** is a full-stack text-to-speech web application that converts user-entered text into speech directly in the browser. It provides a simple, interactive interface for speech playback, text analysis, and optional offline audio generation.

### ✨ Features

* 🔊 Text-to-speech using the browser Web Speech API
* 🐍 Optional offline speech generation using `pyttsx3`
* 📊 Word, character, and sentence count
* ⚡ React + TypeScript responsive frontend
* 🔗 Flask REST API for backend communication
* 📁 JSON-based storage without a database
* ⚙️ Environment configuration using `python-dotenv`
* 🧪 Backend testing with `pytest`

### 🛠️ Tech Stack

**Frontend:** React, TypeScript, Vite, Tailwind CSS
**Backend:** Python, Flask, Flask-CORS
**Speech:** Web Speech API, pyttsx3
**Storage:** JSON
**Testing:** pytest
**Package Management:** Node.js, pnpm

> **Note:** Robo Speaker is a text-to-speech application and does not use custom AI/ML models, neural networks, or external AI APIs.
